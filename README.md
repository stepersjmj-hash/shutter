# 셔터 카운트 감정서

카메라에서 나온 **원본 사진 한 장**으로 셔터 카운트(셔터 작동 횟수)를 확인하는 무료 웹 도구입니다.

**👉 바로 사용하기: https://stepersjmj-hash.github.io/shutter/**

## 특징

- **업로드 없음** — 파일은 서버로 전송되지 않고, 브라우저 안에서만 분석됩니다. 파일 앞부분 몇 MB만 읽어 대용량 RAW도 즉시 처리됩니다.
- **설치 불필요** — 모던 브라우저(Windows/macOS/Linux/모바일)에서 바로 동작합니다.
- **"감정서" 스타일 결과** — 판독 도장, 촬영 정보표, 제조사 내구 기준 대비 위치 스케일을 함께 보여줍니다.

## 사용법

1. 사이트를 열고 **카메라에서 꺼낸 원본 JPG 또는 RAW 파일**(ARW · NEF · PEF · RAF · CR2 · CR3 · DNG)을 드래그하거나 클릭해 선택합니다. 여러 파일 동시 가능.
2. 결과 카드에서 기종, 촬영 일시, 셔터 카운트를 확인합니다.

라이트룸 내보내기·메신저 전송본·리사이즈된 파일은 제조사 메타데이터가 제거되어 판독되지 않을 수 있습니다.

## 개발

정적 사이트라 빌드가 없습니다. 로컬 실행:

```bash
npx -y serve -l 5500 .
```

파서 테스트:

```bash
node test/run-tests.mjs
```

셔터 카운트 태그·오프셋 정보는 [ExifTool](https://github.com/exiftool/exiftool) 문서를 참고했습니다. 결과는 참고용이며, 수리 이력 등에 따라 실제 사용량과 다를 수 있습니다.
